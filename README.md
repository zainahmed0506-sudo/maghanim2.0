# Maghanim

Bilingual English/Arabic marketing website for Maghanim, built with Next.js, React, and TypeScript.

## Local development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm start
```

The homepage includes a centered coin hero, solutions, governance, and a contact section. The contact action displays a coming-soon notice; no enquiry backend is connected.

Brand assets are in `public/`. Visual guidance is recorded in `DESIGN.md`.
